# IBVOID — the layer underneath

An interactive portfolio built as one continuous WebGL instrument.

The opening Pixel-Ripper frame becomes a voxel relief, then the same field is
rewritten through six scroll-driven states: the measured Go allocation
distribution, the 32→64 byte split, upstream commit topology, four project
machines, and the merged commit hash.

No framework, package install, or build step. The runtime is plain HTML, CSS,
JavaScript, WebGL 1, and two local render assets.

## Run locally

```powershell
cd D:\BVoid\Work\oss\IBlackVoid.github.io
python -m http.server 8000 --bind 127.0.0.1
```

Open <http://127.0.0.1:8000/>.

- Move the pointer to bend the glyph field.
- Hold the pointer, press **Lens**, or press <kbd>L</kbd> to inspect the shaded
  voxel world beneath the glyph pass.
- Press **Motion** or <kbd>M</kbd> to freeze the instrument.

Reduced-motion preferences disable continuous rendering and preserve a composed
still. If WebGL is unavailable or the context is lost, the Pixel-Ripper poster
remains visible.
